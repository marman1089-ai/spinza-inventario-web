# Aggiornamento riconoscimento materie prime

Questa versione migliora la classificazione automatica delle uscite, soprattutto per **materie prime** e **fornitori di bibite/food**.

## Cosa riconosce meglio

Vanno in **Materie prime** anche voci come:

- Sapori di Toscana / Sapori Toscana
- Sogegross, Sogergross, Socialgros, Socialgross
- Metro, Metro Cure, Metro Le Cure
- Carrefour, Esselunga, Coop, Conad, Lidl, Aldi, Pam
- Forno, Panificio, Molino
- Macellaio, Macelleria, Carne, Buns
- Caffè / Coffee
- Prinz
- Kombucha, Legendari / Leggendari
- Icaro
- fornitori bibite, birre, soft drink, acqua golden, ecc.

## Correzione dati già inseriti

Dopo il deploy, aprire **Uscite** e premere:

**Ricalcola categorie già inserite**

Il programma corregge anche voci vecchie finite in categorie generiche o sbagliate quando riconosce chiaramente un fornitore food/bibite.

## Nota importante

Le spese con nomi di persona continuano a essere trattate come **Stipendi/personale**, salvo quando il testo contiene un fornitore food/bibite riconosciuto in modo forte.
